Pack Windows 98 SE FR - CD 1 : installation de base (v3)
=========================================================

Lancement
---------
 - Depuis le CD : il demarre tout seul (AUTORUN.EXE), cliquez sur
   "Installer Windows 98 SE FR". Laissez le CD dans le lecteur jusqu'a
   la fin : l'installation redemarre Windows plusieurs fois et reprend
   toute seule.
 - Depuis un dossier du disque dur : copiez tout le contenu du CD dans
   un dossier, puis double-cliquez sur AUTORUN.EXE ou sur INSTALL.BAT.

Fermez tous les programmes avant de commencer. Si un installeur propose
de redemarrer, repondez NON : c'est INSTALL.BAT qui redemarre au bon
moment.

Ordre conseille
---------------
 1. Ce CD (INSTALL.BAT).
 2. Les pilotes : carte graphique, son, etc.
    Deux cartes son (ex. ESS Allegro + SoundMAX integre) : en lecture par
    defaut (Panneau de configuration > Multimedia > Audio), choisir celle
    qui accelere DirectSound (ESS). Avec la SoundMAX, Battlefield 1942
    tombait de 15 a 4 images/s (son mixe par le processeur). Pour un jeu
    qui a besoin de l'autre carte (son CD numerique) : Raccourci de jeu.
    Certains jeux plantent avec le pilote ESS (ecran bleu "exception 00
    dans DSOUND.VXD" ou redemarrage, ex. The Nomad Soul) : Raccourci de
    jeu avec la SoundMAX pour ce jeu.
 3. Le CD 2 (Win98FR_Plus) : DirectX (8.1, 8.2 ou 9.0c, a installer en
    premier : sans lui, la plupart des jeux ne demarrent pas), MS Agent,
    logiciels, jeux, outils de test et outils systeme (MMC, RegClean,
    SharedDLLs).
