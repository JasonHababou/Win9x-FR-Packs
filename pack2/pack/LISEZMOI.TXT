Win98FR - Pack 2 (Win98FR_Plus) : Windows 98 SE et Windows Me
==============================================================
A lancer APRES :
 1. l'installation de base (CD 1 : INSTALL.BAT) ;
 2. l'installation des pilotes (carte graphique, son...).

Depuis le CD, le menu s'ouvre tout seul (AUTORUN.EXE).
Deux facons d'installer, au choix (elles font la meme chose et utilisent
le meme dossier applis) :
 - INSTALLER_PLUS.EXE : installeur Windows avec cases a cocher, groupees
   (Navigateurs, Multimedia, Utilitaires, Bureautique et Internet, Jeux,
   Outils de test) ;
 - PLUS.BAT : une question O/N par element, dans une fenetre MS-DOS.

DirectX (une seule version : 8.1, 8.2 ou 9.0c ; Windows 98 SE a
DirectX 6.1 d'origine, Windows Me la 7.1) et MS Agent 2.0 FR : installes en premier.
Sans DirectX 8 ou 9, la plupart des jeux et 3DMark2001/03 ne demarrent
pas. 9.0c conseille ; 8.1 ou 8.2 pour les jeux qui buguent avec
DirectX 9 (certains jeux Cryo : Egypte, Ubik...). Ce CD est commun au
pack classique (CD 1) et a l'ISO Win98FR.

Logiciels : Firefox 31.8 ESR FR (KernelEx),
VLC 3.0.24 FR (KernelEx, experimental), WinRAR 3.93 FR, ImgBurn 2.5.8.0 FR,
AIDA32 3.93, CPU-Z 1.78 (detection du materiel ; SIV est dans le pack 1), Winamp (5.2 Standard ou Full en anglais, ou 2.91 FR),
XnView 1.80, Foxit Reader 1.3 (anglais), K-Lite Codec Pack 3.4.5.
Bureautique et Internet (INSTALLER_PLUS.EXE seulement, pas dans PLUS.BAT) :
OpenOffice.org 2.4.2 FR (sans Java ; Windows Installer 2.0 installe s'il
manque, puis relancer le pack 2), AbiWord 2.2.7 + dictionnaire FR,
Spread32 (tableur), Nvu 1.0 FR + dictionnaire, Flash Player 9 (IE et
Firefox/RetroZilla), UltimateZip 2.7 (anglais : il s'ouvre apres
l'installation, repondre No a la question des archives pour les laisser
a 7-Zip), FTP Commander (anglais, installation guidee).
Jeux (C:\Jeux, menu Programmes\Jeux) : Hover! FR, SkiFree, Echecs,
Microsoft Puzzle Collection (10 jeux, francais, sans installation guidee).
Outils de test : 3DMark99 Max, 3DMark2000, 3DMark2001 SE, 3DMark03 3.4.0
(installations guidees, cles dans C:\WINDOWS\BENCH_CLES.TXT ; 3DMark03
exige DirectX 9).
Outils systeme (anglais) : console MMC 1.2, RegClean et SharedDLLs.
Fraps, WinTop et DAEMON Tools sont dans le pack 1 et dans l'ISO.

Firefox, VLC, les jeux et la Puzzle Collection sont compresses
(archives .7Z) et decompresses a l'installation par applis\outils\7Z.EXE
(7-Zip 9.20) : une fenetre MS-DOS s'ouvre quelques secondes, c'est normal.

KernelEx (applis\kernelex\KEX2019.EXE) est installe automatiquement si
Firefox ou VLC est choisi et qu'il manque (desactive par defaut,
actif seulement pour ces programmes) ; un redemarrage est alors propose.
